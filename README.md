# 🎓 College Admission Form

A simple and responsive College Admission Form built using HTML and CSS.

## 📖 About The Project

This project is a web-based admission form designed to collect student information for college admissions. It includes sections for personal details, contact information, academic details, and a declaration checkbox.

## ✨ Features

- Personal Information Section
- Contact Information Section
- Academic Information Section
- Declaration Checkbox
- HTML Form Validation
- Clean and Simple User Interface

## 🛠️ Built With

- HTML5
- CSS3

1. Clone the repository:

